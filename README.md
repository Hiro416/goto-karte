# CBT 誤答ノート

テコプラCBTとQBオンライン医学共用試験CBTで、表示中の誤答をChrome内に保存する非公式のChrome拡張です。

**開発中の試作版（0.2.0）です。** 抽出・保存処理を単体検証していますが、実ブラウザでの一連の操作は未検証です。導入後、まず1問で問題文・自分の回答・正答・解説の保存内容を確認してください。

## できること

- 不正解の問題を自動保存。正解の問題も手動で追加
- 両サービスの誤答をまとめて検索し、サービス・分野・復習状況で絞り込み
- 問題文、選択肢、自分の回答、正答、解説、取得できる分野情報を保存
- メモと復習済みの状態を記録
- 表示中の問題をMarkdownに書き出し
- 全件をJSONでバックアップ・復元

画像は参照URLのみを保存します。画像ファイル本体の保存やオフライン表示には対応していません。

## 導入

1. このリポジトリをダウンロードして展開するか、Gitで取得します。
2. `manifest.json` が入ったフォルダを、そのまま使い続けられる場所へ置きます。
3. Chromeのアドレス欄で `chrome://extensions` を開きます。
4. 「デベロッパーモード」をオンにします。
5. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が入ったフォルダを選びます。
6. テコプラまたはQBの演習ページを再読み込みします。
7. 解答後、右下に「問題 ○○ を保存済み」と表示されたことを確認します。

Chromeの拡張メニューから「CBT 誤答ノート」をクリックすると、ノートが別タブで開きます。ピン留めすると便利です。

## 使い方

不正解の問題を開くと自動保存します。解答済みの正解問題は、右下の「この問題を手動保存」で追加できます。

テコプラの△・ヒント使用判定も保存したい場合は、ノートの設定をオンにしてください。QBの自己評価による△の自動追加は未対応です。

メモや復習状況を変更したら「メモを保存」を押します。問題の切り替えや書き出しの際にも保存します。

「表示中をMarkdownに」は現在の絞り込み結果を、「全件をJSONでバックアップ」はメモ・復習状態を含む全件を書き出します。JSONの復元では、既存の同じ問題を上書きせず、新しい問題だけを追加します。

## 更新とデータの引き継ぎ

1. 現在のノートからJSONでバックアップします。
2. 以前Chromeへ読み込んだフォルダ内のファイルを、新しい内容で上書きします。
3. `chrome://extensions` の更新ボタンを押し、演習ページを再読み込みします。

同じ場所の拡張を更新すれば、保存データを引き続き使えます。別フォルダに新規導入した場合は、JSONを復元してください。0.1.0のテコプラ版JSONにも対応しています。

**拡張を削除すると、保存データも消えます。定期的にJSONでバックアップしてください。** データはChromeのプロファイルごとに保存され、他端末には同期されません。容量は通常の拡張ストレージの上限（約10MB）です。

## 対応範囲

| サービス | 対象 |
| --- | --- |
| テコプラ | `https://m3e-medical.com/users/cbt/*` の対応する問題演習画面 |
| QBオンライン | `https://cbt.medilink-study.com/quiz` の医学共用試験CBT演習画面 |

模試や国試の別画面は未対応です。サイト側のHTML変更で動作しなくなる場合があります。

QBは演習中にURLが現在の問題を表さない場合があるため、画面内の問題IDで重複を防ぎます。ノートからQBを開いた際は、保存した問題番号と照合してください。正答は画面の「正解：」欄から取得し、解説中の○×からは推測しません。

自分の回答は、現在の選択状態や表示された履歴から取得します。取得できない場合は「取得できず」と表示します。解答記録は観察した範囲に限るため、記録数を総演習回数や総誤答回数としては使えません。

## データの扱い

データは端末内の `chrome.storage.local` に保存します。拡張から外部サーバーへ学習内容を送信する処理、AI APIの呼び出し、問題の自動巡回はありません。保存するのは現在の問題に必要な項目です。Cookieや認証トークン、ページ全体は保存しません。

問題・画像へのリンクは、自分でクリックしたときにそのサイトが開きます。閲覧には各サービスへのログインが必要な場合があります。

このリポジトリには、各サービスの問題文・解説・画像、実際の学習履歴、保存HTMLは収録していません。教材の取り扱いは各サービスの利用条件に従ってください。本拡張は各サービスの運営元による公式製品ではありません。

詳細は [PRIVACY.md](PRIVACY.md) を参照してください。

## 開発・検証

拡張の使用にビルドや追加パッケージは不要です。単体テストにはNode.js 22以降を使用します。

```sh
npm test
```

`npm install` は不要です。公開テストはすべて架空データを使います。DOM抽出のテストはインメモリDOMアダプターによるもので、実ブラウザやChrome拡張APIの完全な再現ではありません。保存用APIはモックで検証しています。

公開版の検証範囲は [VALIDATION.md](VALIDATION.md) を参照してください。

不具合を報告する場合は、拡張のバージョン、サービス名、再現手順、実際の表示を添えてください。認証情報、問題全文や解説全文、学習データのバックアップは公開Issueに添付しないでください。
